Система обработки изображений со стереокамер разделена на несколько модулей:

- Выравнивание изображений в стереопаре (image rectification).
- Оценка глубины (с помощью BANet).
- Семантическая сегментация (с помощью RF-DETR).
- Объединение и постобработка масок объектов и карты глубины.
- Обнаружение и отслеживание движущихся объектов.
- Обнаружение статичных препятствий.

Взаимодействие между модулями осуществляется исключительно с использованием каналов (или по сети, при необходимости выполнять модули на разных устройствах). 

Модуль оценки глубины создаёт карту глубины для каждой стереопары на входе.

Модуль семантической сегментации обнаруживает объекты на изображениях и создаёт ограничивающие рамки (прямоугольная область изображения, содержащий объект) для каждого объекта, а также создаёт маски объектов (определяет, частью какого объекта является каждый пиксель изображения). 

Модуль "объединение и постобработка масок объектов и карты глубины" объединяет изображения, карту глубины и семантическую сегментацию со всех стереокамер в одно облако точек (один из метод представления трёхмерных поверхностей, при котором используется массив точек), что позволяет абстрагировать дальнейшие модули от факта наличия и расположения нескольких камер.

Модуль обнаружение статичных препятствий выполняет дальнейшую обработку облака точек для обнаружения статичных препятствий. Результаты работы модуля возвращаются в виде двухмерной карты препятствий, представляющую собой проекцию препятствий на плоскость дороги.

Модуль обнаружения и отслеживания движущихся объектов выполняет дальнейшую обработку облака точек для обнаружения, оценки скорости и размеров движущихся объектов - автомобилей, пешеходов. Результаты работы модуля возвращаются в виде набора двумерных ограничивающих рамок с поворотом.

Параметры калибровки должны содержать следующие значения:
- Матрица 4×4 для преобразования координат в системе координат кадра ([x, y, disparity(x, y)]) в систему координат автомобиля.
- Положение камер относительно центра автомобиля, для возможности объединения данных с нескольких камер.

Для корректной работы модуля "объединение и постобработка масок объектов и карты глубины" необходимо получать все данные с датчиков в один момент времени. По этой причине перед началом обработки изображения со всех стереокамер объединяются в один пакет, после чего объединяются с данными о положении автомобиля в одну структуру со следующими полями:

- Массив изображений со стереокамер.
- Положение, направление и скорость автомобиля.
- Время, в которое были получены данные.

Поскольку модули используют для обработки данных нейронные сети, требующие значительное количество памяти, для минимизации используемых ресурсов запускается только один экземпляр каждого модуля.
